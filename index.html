Recoup

AI agents for failed payment recovery

A prototype for subscription businesses on Paystack and Flutterwave. When a recurring charge fails, an agent holds a recovery conversation over a WhatsApp style chat in English or Pidgin and closes it with a payment link, a scheduled retry or a handoff to a person.

  • A LangGraph flow that routes each case, retrieves the right playbook for the decline code and escalates disputes to a human every time.
  • An evaluation harness of 28 scenarios that raised action correctness from 86% to 100% and routing accuracy from 96% to 100%.
  • Runs on synthetic data out of the box, with no payment or WhatsApp keys needed.
  • Python
  • LangGraph
  • FastAPI
  • pgvector
  • Anthropic and OpenAI
  • Docker
  • GitHub Actions
